# Contributor Documentation

This folder contains documentation for contributors, separate from the materials themselves in `src/`. (Sample files and other examples that are best shown in the form of a file live here as well.)

- [Writing Documents](writing-documents.md): The markdown syntax used by this project, including the pandoc extensions that give documents additional flexibility.
- [Style Guide](style-guide.md): Guidelines for what should/shouldn't be in a document, and how to arrange content.
- [Sample File](sample-file.md): A fully commented example document demonstrating everything. (`mountain.jpg` is a sample image used by it.)
- [Extra Credits](extra-credits.md): A centralized record of external sources, links, and credits for the materials.

See [CONTRIBUTING.md](../CONTRIBUTING.md) for the rest of the contributor guide, including environment setup and building the project.
